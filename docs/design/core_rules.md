# 核心规则

状态：已确认需求；可运行框架原型已实现，暂定细节见 `../planning/phase_01.md`。

## 已确认：产品与范围

- 修仙题材横版增量放置游戏，参考《Zad Archery》的战斗与成长循环。
- 首发仅 Windows，使用 Godot .NET 和 C#。
- 1920×1080 设计尺寸，等比缩放；上半区战斗，下半区养成操作。
- 初期角色在地面行走。御剑系统留待后续，不属于当前五大系统。
- 当前五大系统为剑途、剑境/剑诀、铸剑、剑意、剑灵；后续支持新增与长尾系统。
- 不做转生，不重置长期养成。
- 最小化继续挂机；退出游戏停止一切产出，无离线收益。

## 已确认：关卡与移动

- 初期配置 100 关，实际关卡数量由配置决定，可扩展。
- 每关长度一致，25 格，每格对应一屏逻辑距离；最后一格为 BOSS 格。
- 角色具有配置决定的移动速度，通常不随养成改变。
- 清空攻击距离内的怪物后，角色自行移动。不能用清怪后直接跳格代替移动。
- 攻击距离内出现合法怪物目标时停下，清空后继续移动；远处仍有怪物不阻止前进。
- 进入对应格时激活该格刷怪点，随后定时刷新；未进入的远处格不提前刷怪。
- 角色越过刷怪点后，该点才停止刷怪。走路时尚未越过的刷怪点仍可能刷新怪物。
- 波次间隔结束时，即使上一波未清空，仍叠加新怪。
- 场上全部怪物清空时，可以继续前进。
- 手动返回旧关卡后，在选定关卡整关循环。
- 到达配置中的最后一关后，循环当前关。

## 已确认：BOSS 与裂隙

- BOSS 格出现 BOSS、怪物与时空裂隙。
- 裂隙使用 `monster.csv` 配置，是有 HP、不移动、不攻击的特殊怪物单位。
- 必须清空所有战斗怪物（包括 BOSS，不包括裂隙自身）才能攻击裂隙。
- BOSS 死亡后，小怪停止刷新。
- 清空战斗怪物并击碎裂隙后，才满足传送条件。
- 每关首次击杀 BOSS 时立即发放且仅发放 1 个妖核，重复击杀不给妖核；无需等到裂隙击碎或关卡通关。
- 首杀按稳定关卡 ID 记录，不按怪物模板 ID 记录；不同关卡复用同一 BOSS 模板时仍各有一次首杀。
- 妖核作为定量投放资源，当前五大系统不提供其他产出来源。累计投放量等于已完成 BOSS 首杀的关卡数，100 关最多投放 100 个；背包余额会因消耗而减少。
- 首次与重复奖励仍分开配置，重复奖励可以配置其他资源，但不能包含妖核。

## 已确认：死亡

- 普通格死亡：回到当前关卡第一个节点，重置该关推进进度，不损失任何资源。
- BOSS 格死亡：角色满血在当前格安全位置重生，前面的格不重新刷怪，不损失资源。
- 保留本格存活怪物的剩余 HP 与已击杀状态；已死亡的 BOSS 保持死亡，小怪保持停止刷新。
- 可以通过多次复活积累对 BOSS 的伤害，不重置整场 BOSS 遭遇。
- 已领取的首杀奖励不因死亡、重试或整关循环而重置。

## 已确认：战斗

- 所有角色技能均为远程技能，包括子弹、定点目标、地面持续、Buff 和召唤等类型。
- 5 个境界，每个境界关联 3 个技能；需先解锁境界，再解锁与强化技能。
- 15 个技能解锁后全部自动释放，独立冷却；没有合法目标时不空放。
- 角色在地上或未来御剑飞行时，都能被攻击，不判断跳跃或空地可攻击性。
- 画面上方显示角色 HP 条。
- 怪物具有攻击距离，支持近战、远程、法术攻击；进入攻击距离后停下攻击。
- 怪物允许重叠，不用实体阻挡形成排队。

## 已确认：养成

- 剑途：从左向右发展，只显示已加点及相邻节点；纵向最多 5 行，横向可扩展。消耗金币和妖核，提供属性、技能、功能解锁及功能强化。
- 铸剑：打造、穿戴、强化、洗练，只有一个武器装备位。
- 剑意：参悟获得 4 类货币；4 个强化子页面用于强化 15 个剑诀。
- 剑灵：独立悬浮作战单位，可以抽取，最多同时装备 3 个；每个可装备 3 种不同的增强 Buff。
- 技能详细设计、剑途节点与规则、铸剑细节后续补充，不自行视为已定方案。

## 已确认：参悟与收取

- 参悟采用类似挖矿的点击交互，后续解锁自动参悟。
- 参悟页面打开期间，战斗继续。
- 离开参悟页面后，在线自动参悟继续，未收取产物保留。
- 产物可以合并数量，积存上限可以配置。
- 鼠标移到产物上即可收取，不要求按住鼠标。
- 退出游戏不继续生产。

## 框架确认状态

刷怪激活与推进、BOSS 格死亡保留状态、妖核首杀定量投放均已确认，当前没有需要再次确认的框架阻塞项。技能、天赋、铸剑等内容细节按后续系统设计补充。

## 实现建议（尚未确认为规则）

- 角色使用独立的推进停止距离；各技能射程独立，远射程技能不必改变角色停步位置。
- 刷怪点使用稳定 ID 和世界横坐标，格号用于区域划分及 UI；“越过刷怪点”只关闭该点后续刷新，不删除已生成怪物。
- BOSS 首杀与关卡首通分开记录；首杀标记、累计投放和背包奖励在同一次存档提交中保存。
- BOSS 格复活保留裂隙剩余 HP 与解锁状态；复活过渡期间冻结本格战斗与刷怪计时，避免复活等待导致无操作机会的堆怪。
- 未收取参悟产物随存档保留，容量满时停止继续生产，不自动兑换入背包。
- 退出/重进时战斗恢复粒度、Buff 与技能冷却恢复方式另行明确；不计算退出期间收益。
